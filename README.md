# INFOMDSS Test App

Basic Flask dashbaord to serve as template for INFOMDIS group project. Based on the [SB Admin Bootstrap](https://startbootstrap.com/template/sb-admin) template.

## Structure

```
app.py                  Flask routes
modules/data.py          Loads employee data + chart data
data/employees.csv       Employee table data
templates/               Jinja2 templates (base.html + pages)
static/                  CSS, JS, images
```
